# TextPilot - 产品需求规格说明书 v1.0

---

## 一、产品概述

| 项目 | 说明 |
|------|------|
| 产品名称 | TextPilot |
| Slogan | AI 驾驭你的文字 |
| 平台 | Windows |
| 技术栈 | Electron + Web 前端 |
| 目标用户 | 小范围分享（朋友/团队） |
| 核心定位 | AI 驱动的剪贴板文本处理工具，Raycast 风格交互 |

---

## 二、核心流程

```
快捷键唤起 → 自动读取剪贴板（可为空） → 选择/搜索动作 → AI处理 → 预览编辑 → 确认输出到剪贴板
```

| 步骤 | 说明 |
|------|------|
| 唤起 | 全局快捷键 或 托盘图标 或 动作独立快捷键 |
| 剪贴板 | 有内容则作为 `{{clipboard}}`；为空则模板自行处理 |
| 选择动作 | 搜索框筛选，键盘/鼠标选择 |
| AI 处理 | 调用配置的模型 API |
| 预览 | 可编辑结果，支持重新生成 |
| 输出 | 确认后自动写入剪贴板 |

---

## 三、交互设计

### 3.1 唤起方式

| 方式 | 说明 |
|------|------|
| 全局快捷键 | 默认 `Ctrl + Shift + V`，可自定义 |
| 系统托盘 | 左键点击打开主界面 |
| 动作快捷键 | 常用动作可绑定独立快捷键，直接执行（跳过选择） |

### 3.2 主界面（Raycast 风格）

```
┌─────────────────────────────────────┐
│  🔍 搜索动作...                      │
├─────────────────────────────────────┤
│  ⏱ 最近使用                          │
│    ├─ ✨ 润色文本           Ctrl+1   │
│    ├─ 🌐 翻译成英文         Ctrl+2   │
│    └─ 📝 扩写               Ctrl+3   │
├─────────────────────────────────────┤
│  📁 全部动作                          │
│    ├─ ...                           │
│    └─ ...                           │
└─────────────────────────────────────┘
```

- 居中浮窗，宽度约 600px
- 顶部搜索框，实时模糊筛选
- 列表分区：最近使用 → 全部动作
- 显示动作绑定的快捷键
- 键盘导航：`↑↓` 选择，`Enter` 执行，`Esc` 关闭

### 3.3 预览界面

```
┌─────────────────────────────────────┐
│  ✨ 润色文本 - 预览                   │
├─────────────────────────────────────┤
│                                     │
│  [可编辑的结果文本区域]               │
│                                     │
├─────────────────────────────────────┤
│  🔄 重新生成    ✅ 确认    ❌ 取消    │
└─────────────────────────────────────┘
```

- 结果可直接编辑修改
- 确认：复制到剪贴板 + 关闭窗口
- 重新生成：重新调用 AI
- 取消：返回动作列表

### 3.4 托盘菜单

- 打开 TextPilot
- 快捷动作（显示已绑定快捷键的动作）
- 设置
- 历史记录
- 退出

## 四、快捷键系统

### 4.1 快捷键类型

| 类型 | 说明 | 示例 |
|------|------|------|
| 全局唤起 | 打开主界面 | `Ctrl + Shift + V` |
| 动作快捷键 | 直接触发指定动作 | `Ctrl + Alt + 1` |

### 4.2 快捷键管理

- 设置界面统一管理
- **冲突检测**：设置时自动检测系统及应用内冲突，提示用户
- 支持清除/重置

## 五、AI 能力

### 5.1 模型支持

| 类型 | 说明 |
|------|------|
| OpenAI | GPT-4 / GPT-4o / GPT-3.5 |
| Claude | Claude 3 系列 |
| 本地模型 | Ollama 等本地部署 |
| 自定义 | 任意兼容 OpenAI API 格式的服务 |

### 5.2 模型配置

- 用户自带 API Key
- 可添加多个模型配置
- 每个动作/模板可指定使用哪个模型
- 设置默认模型

## 六、用户偏好系统

### 6.1 偏好维度

| 维度 | 选项示例 |
|------|----------|
| 写作风格 | 正式 / 轻松 / 简洁 / 详细 |
| 专业领域 | 技术 / 商务 / 学术 / 创意 / 通用 |
| 语言偏好 | 中文 / 英文 / 自动检测 |
| 个人信息 | 姓名、公司、职位、邮箱、签名等 |

### 6.2 长期上下文

用户可定义持久背景信息，始终作为 System Prompt 一部分：

```
示例：
我是一名嵌入式开发工程师，主要使用 ESP32 + ESP-IDF 框架。
日常使用中英文混合沟通，偏好简洁专业的表达风格。
```

### 6.3 偏好生效方式

所有偏好自动注入 System Prompt，每次 AI 调用始终生效。

## 七、模板系统

### 7.1 模板管理

| 操作 | 说明 |
|------|------|
| 内置预设 | 提供 3 个默认模板 |
| 新增 | 用户自定义新模板 |
| 编辑 | 修改任意模板（含内置） |
| 删除 | 删除任意模板 |
| 导入/导出 | JSON 格式 |

### 7.2 模板变量

| 变量 | 说明 |
|------|------|
| `{{clipboard}}` | 当前剪贴板内容 |
| `{{date}}` | 当前日期（如 2025-01-15） |
| `{{time}}` | 当前时间（如 14:30） |
| `{{user.name}}` | 用户姓名 |
| `{{user.company}}` | 用户公司 |
| `{{user.xxx}}` | 其他自定义个人信息字段 |

### 7.3 MVP 内置模板

**① 润色文本**
```
请润色以下文本，保持原意，使表达更流畅专业：

{{clipboard}}
```

**② 翻译成英文**
```
请将以下内容翻译成地道的英文：

{{clipboard}}
```

**③ 扩写**
```
请基于以下内容进行扩写，丰富细节和论述，使内容更加完整充实：

{{clipboard}}
```

### 7.4 模板配置项

| 配置 | 说明 |
|------|------|
| 名称 | 显示名称 |
| 图标 | Emoji 或图标 |
| Prompt | 模板内容 |
| 快捷键 | 可选绑定 |
| 指定模型 | 可选，否则用默认模型 |
